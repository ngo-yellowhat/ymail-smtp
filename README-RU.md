# Ymail-smtp

SMTP сервер прямой доставки писем - принимает письма от клиентов и пересылает их получателям напрямую через **DNS MX Lookup** ( без промежуточного relay )

Написан на библиотеках:
- [Cobra](https://github.com/spf13/cobra/)
- [go-smtp](https://github.com/emersion/go-smtp)
- другие стандартные библиотеки Go

## Возможности
- Прием писем
- Прямая доставка получателю
- STARTTLS при доставке, если поддерживается получателем
- Не хранит письма - только транзитная пересылка

## Запуск

```shell
git clone https://github.com/ngo-yellowhat/ymail-smtp
cd ymail-smtp
make build run
```
запустит smtp-сервер на localhost:2525
см. [Makefile](Makefile)

### Docker

```shell
git clone https://github.com/ngo-yellowhat/ymail-smtp
cd ymail-smtp
make build-docker run-docker
```
Контейнер запускается с флагом `--network=host` - используя сетевой стек хоста напрямую ( без проброса портов ). Это означает, что порт, на котором слушает сервер внутри контейнера, доступен на хосте под тем же номером порта без доп. настроек
см. [Dockerfile](Dockerfile)

## Тестирование
```shell
telnet localhost 2525
```
Или другой порт, который вы указали
При тестировании через `netcat` (nc) возможны проблемы: `nc` по умолчанию использует '\n' вместо требуемого протоколом '\r\n', из-за чего завершающая точка DATA может не распознаваться сервером. Рекомендуется `telnet` или реальный SMTP-клиент (например, Python с smtplib) для надёжного теста

***

## Мелкие предупреждения
1. Нет аутенфикации между серверами
2. Порт 25 в большинствах случаях блокируется домашним интернет провайдером ( в мерах безопасности от спам-ботов )
3. Cервер обрабатывает каждого получателя отдельно ( одно подключение на каждого клиента )
